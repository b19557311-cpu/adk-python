# Simple Researcher & Formatter Workflow

This is a multi-agent ADK 2.0 workflow sample designed for beginners. It demonstrates how two specialized agents can collaborate on a single research assignment.

## Workflow Overview

1. **Researcher Agent**: Gathers rich, detailed information on a specified topic. It can use Google Search integration to fetch live information from the web.
2. **Formatter Agent**: Takes the researcher's raw outputs and converts them into a beautiful, well-formatted Markdown document.

## Running the Sample

To run this workflow, follow the setup instructions in the main [GETTING_STARTED.md](../../../../GETTING_STARTED.md).
